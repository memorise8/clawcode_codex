## 1. OpenAI Codex OAuth 통합

### 문제
claw-code는 Anthropic API 전용으로, Claude 계정이 필수였습니다.

### 해결 과정

1. **조사**: Codex OAuth 사용 가능 여부 확인 -> Anthropic OAuth는 서드파티 금지, OpenAI Codex OAuth는 허용
2. **Chat Completions API 시도**: `api.openai.com/v1/chat/completions` -> 실패 (ChatGPT OAuth 토큰은 `model.request` 스코프 없음)
3. **Responses API 시도**: `api.openai.com/v1/responses` -> 실패 (`api.responses.write` 스코프 없음)
4. **토큰 교환 시도**: RFC 8693 토큰 교환 -> 부분 성공, id_token 만료 문제
5. **최종 해결**: `chatgpt.com/backend-api/codex/responses` 엔드포인트 발견
   - OpenCode의 `opencode-openai-codex-auth` 플러그인 분석
   - ChatGPT OAuth 토큰은 `chatgpt.com/backend-api` 전용
   - 필수 헤더: `openai-account-id`, `openai-beta: responses-v1`, `openai-originator: codex_cli_rs`
   - 필수 body: `store: false`, `instructions` 필드

### 구현 파일

| 파일 | 용도 |
|------|------|
| `api/src/openai_types.rs` | OpenAI Chat Completions + Responses API 타입 |
| `api/src/openai_client.rs` | OpenAI HTTP 클라이언트 (retry, SSE 스트리밍, ChatGPT backend 라우팅) |
| `api/src/openai_auth.rs` | 인증 (env var -> OAuth 저장소 -> ~/.codex/auth.json -> JWT 디코딩 -> 토큰 갱신) |
| `api/src/error.rs` | `MissingOpenAiKey`, `OpenAiApi` 에러 variant |
| `runtime/src/oauth.rs` | provider별 credential 저장/로드 함수 |
| `rusty-claude-cli/src/main.rs` | Provider enum, ProviderClient, OpenAiRuntimeClient, login/logout |

### 인증 플로우

```
~/.codex/auth.json (codex login으로 생성)
  -> tokens.access_token + tokens.account_id 읽기
  -> JWT exp 확인 -> 만료 시 refresh_token으로 갱신
  -> POST https://chatgpt.com/backend-api/codex/responses
  -> Headers: Authorization, openai-account-id, openai-beta, openai-originator
```

### 사용법

```bash
claw --provider openai --model gpt-5.4 prompt "hello"
claw --provider openai --model gpt-5.4  # REPL
```

## 2. Responses API 멀티턴 도구 호출

### 문제
Responses API의 도구 호출/결과 형식이 Anthropic과 다릅니다.

### 해결
- `function_call` / `function_call_output` 입력 항목 타입 추가
- `convert_to_responses_input()` 함수에서 올바른 형식으로 변환
- function call ID 형식: API는 `fc_xxx` (item ID) + `call_xxx` (call ID) 두 개를 사용
  -> `fc_xxx:call_xxx` combined 형식으로 인코딩/디코딩

### 테스트 결과
```
모델 -> bash 도구 호출 -> ls 실행 -> 결과 표시 -> 추가 대화 (멀티턴 성공)
```
